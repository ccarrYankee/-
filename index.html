Структура страницы

Тег <main> выделяет основное содержание страницы. Тег <header> — это «шапка», а <footer> — «подвал». Тег <nav> отвечает за навигацию, а <aside> — за дополнительное содержание.

Списки

Неупорядоченный список <ul>

  • HTML отвечает за структуру
  • CSS отвечает за внешний вид
  • JavaScript отвечает за поведение

Упорядоченный список <ol> (с атрибутами start, reversed, type)
